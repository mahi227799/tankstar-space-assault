# Tankstar: Space Assault

A simple arcade-style space shooter built with Python and Pygame.

## Features

- Player movement and shooting
- Enemy ships that fire back
- Limited lives
- Score and level system
- Boss battle after reaching 100 points
- Progressive boss difficulty
- Boss incoming warning
- Start menu and scoreboard
- Sound effects and custom assets

## Controls

- Left / Right Arrow Keys: Move
- Space or S: Shoot
- R: Restart after game over
- ESC: Return to main menu

## Requirements

- Python 3
- Pygame

Install Pygame with:

```bash
pip install pygame

Run the game with:
python tankstar.py

About
